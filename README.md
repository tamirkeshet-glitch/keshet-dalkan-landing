# דף נחיתה דלקן — קשת יזמות עסקית / סונול

דף גיוס לעסקים ולמשפחות. הלקוח משאיר פרטים בסיסיים. אין כאן הסכם, חתימה או הזמנה.

## קבצים

- `index.html` — הדף. לוגו קשת מוטמע. שליחה לטופס גוגל כש־`FORM_RESPONSE` מלא.
- `build_dalkan_lead_form.gs` — יוצר את טופס הגוגל וגיליון התגובות.
- `keshet-logo.jpg` — עותק הלוגו (מקור בדרייב: לוגו קשת.jpg).

## טופס גוגל

הסקריפט לא רץ מכאן כי אין התחברות גוגל בסשן. פעם אחת, בחשבון שמחזיק את טפסי JOIN:

1. [script.google.com](https://script.google.com) → פרויקט חדש.
2. להדביק את `build_dalkan_lead_form.gs` ולהריץ `buildDalkanLeadForm`.
3. לאשר הרשאות.
4. מ־Executions / Logger להעתיק `formResponse` ואת מזהי `entry`.
5. להדביק ב־`index.html` בתוך `FORM`.

שדות הטופס, לפי סדר הדף: שם מלא, טלפון, אימייל, יישוב, למי זה, שם העסק או המשפחה, כמה רכבים, מה מעניין, הערה. התגובות נשמרות בגיליון «לידים דף נחיתה דלקן — תגובות».

הדף שולח `POST` אל `formResponse` במצב `no-cors` (כמו טופס ההזמנה). גוגל לא מחזיר אישור לדפדפן; השורה מופיעה בגיליון.

לא לחבר את הטופס הזה לגיליון ההזמנות או ל־JOIN.
